# garment-to-shot

**Garment photo → normalized asset → character sheet → display wall → shot frames.**

面向 AI 短视频（电商/带货）的服装视觉素材生产：商家手里只有**服装照片**，我们要输出**一整套能进短视频的镜头素材** —— 衣服规范化成可复用资产、人物跨镜可识别、多套能一屏陈列并被点选、最后落到具体场景。
