# 视频 A/B 客观指标（00060 vs 00061）

采集方式：ffmpeg 抽 4fps 帧 → 逐帧灰度差（motion）+ 平均亮度（lum）；切点检测；容器指纹。
**注意：两条都是单镜、无切点。**

| 项 | 00060 | 00061 |
|---|---|---|
| 容器 | 832×1440 · 24fps · 192 帧 · 8.000s · AAC 32k 立体声 | 同 |
| 切点 | 0（一镜到底） | 0（一镜到底） |
| 平均运动量 | **16.99** | **19.72** |
| 运动峰值 | 35.09（4.5–5.0s） | 32.27（4.0s） |
| 前 2 秒运动量 | **0.35–4.56（有静场）** | **5.26–15.98（无静场）** |
| 末 1 秒运动量 | 9.66（收住） | 8.26（收住） |
| 平均亮度范围 | 97.9 → 112.8（**偏亮、走高**） | 84.8 → 104.5（**偏暗、对比强**） |

## 三帧读解（1s / 4s / 7s）
- **两条相同的故事弧**：端杯坐着看画外 → 前倾拿茶几上的手机 → 手机到手、屏光照脸、微笑。
- **两条相同的镜头语言**：中景/中远景 → 中景更近 → 近景，**明显推近**；光从环境光转为**手机屏光主导**。
- **区别在节奏**：00060 = 静场 → 2.5s 起爆发 → 收；00061 = 从第一帧就在动，全程均匀偏快。

## 初步对照结论（待用户确认文件↔版本映射）
- 「逐秒编排」写法预期产生**静场 + 明确爆发点** → 与 **00060** 的曲线一致。
- 「连贯描述」写法预期产生**持续动作、无静场** → 与 **00061** 的曲线一致。
- 两条都达成了"事件 + 景别变化 + 光变化"，说明**两种写法都能治摆拍感**；差别是**节奏的可控性**（逐秒版能指定哪一秒停顿）。
