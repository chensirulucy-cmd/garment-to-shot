### 3.3 输出尺寸 = 输入图按 32 对齐

工作流接线（读取 470/472 的 API 图）：

```
459:468 ComfySwitchNode  switch = False
         on_false → 459:474 第 3 个输出（参考图编码出的 latent）← 实际走这条
         on_true  → 459:456 EmptyLatentImage ← 接 ResolutionSelector，被旁路
```

所以 `ResolutionSelector`（9:16 / 1.0 MP / multiple 32）**不决定出图尺寸**。实测 10/10 等于输入图尺寸按 32 对齐：

| 输入 | 输出 |
|---|---|
| 1200×1600（7 张） | 1216×1600 |
| 1200×2124（453） | 1216×2112 |
| 1200×1200（466） | 1216×1216 |
| 614×612（470） | 608×608 |

推论：① 要换画幅只能换输入图；② 尺寸不同的两张图不得互比像素。
