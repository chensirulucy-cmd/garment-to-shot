# 每次跑完必须登记的字段

| 字段 | 说明 |
|---|---|
| 输出文件 | `Qwen_image_2.1_XXXXX.png` / `MiniMax_H3_XXXXX_.mp4`（真名） |
| 模块 | 01-canvas … 09-video-prompt |
| 提示词 | 指向 `prompts/` 下的文件 + 是否为修改版 |
| 参考图 | 每个槽位接了哪张（顺序即位置） |
| seed | **必填**（做对照时必须锁） |
| steps / cfg / sampler | 必填 |
| 尺寸 / megapixels | 必填（实测出现过同提示词两种尺寸） |
| 结论 | 通过 / 失败 / 待定 + 一句话原因 |

> 只记"图好看"没用；**能复算出这张图的参数**才算登记完成。
