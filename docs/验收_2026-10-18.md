## 五、注意事项（按线，全部有实测出处）

**两段式（12）**
1. 服装板 `resolution = 0` → **输出尺寸跟着输入服装照走**（00254 → 1216×1600），不是 1088×1920；两段尺寸不同属正常。
2. 颜色跨两段被抬亮两遍：红裙 G 通道 18.8 → 64.7（深正红变亮砖红），**色彩保真句必须在两段都写**。
3. 面料没有默认值，不写就自由发挥 → 两张图都看不出织法时**不能声称"复刻了材质"**。
4. 负向按段分文件（①禁人 / ②禁白模），粘反会互相抵消。
5. 换姿势只在白模段换；在②里改姿势＝拆掉画布锚，Δ4 不再成立。

**换头（11）**
6. 目标图必须原尺寸进；共用选择器时 `1:1 / 2MP` 会把 1088×1920 压成 800×1440（掉 45% 像素）。
7. 痣/疤"消失"先查尺寸：1088×1920、strength 1.0 时 00373 里痣回来了。
8. `deis_2m` 本机不存在，选了整条 prompt 被丢弃；换 `euler` 画面差 1.58/255。

**通用**
9. 参数以成品 PNG 的 `prompt` chunk 为准，不信交接文档与文件名。
10. UI 版与 API 版节点编号对不上，报改动要按"节点标题 + 接的哪张图 + 当前值"说。
11. 像素差只在同尺寸同裁切下可比；不要用暗像素连通块量脸宽（同一张脸能量出 158 / 197 / 238 三个值）。
12. 编辑＝整图重绘，"其它区域不动"是请求不是保证 —— 这也是单格返修被弃用的根因。
