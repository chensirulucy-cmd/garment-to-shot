## 为什么“编辑线全身换人”被否决（这是本轮调研的起点）

目标：把「人像特写」的脸放到「全身照」身上，其余像素不动。实测结果：

| 轮次 | 出图 | 头宽 | 参考头宽 | 比值 | 失败方式 |
|---|---|---|---|---|---|
| 1 | 768×1376 | 106 px | 553 px | **0.19×** | 只剩白模关节，脸是编的 |
| 2 | 928×1664 | 131 px | 553 px | **0.24×** | 脸糊；**衣服漂成米白 RGB(240,237,233)**；灰圆头低方跟鞋变成裸色尖头高跟 |
| 3 | — | — | — | — | 塌成黑 T 黑裤，服装全丢 |

机制（已确证）：**Qwen 编辑是整图重绘，不是贴图**；参考图只给内容提示，不给像素；提示词只能“劝”，改不改由它。官方原话：`prefer one blanket preservation clause over walking the frame… the more concretely you describe something you meant to keep, the more likely it drifts.` —— 我把衣服逐件描述了一遍，它就重画了一遍。

像素预算表（1920 高时脸能有多大）：全身 236 px / 膝以上 269 / 大腿中 392 / 腰以上 553 / 胸以上 803。**门槛：出图脸 ≥ 参考脸的 1/2**。所以“全身 + 这张脸”在 2 MP 内不可能成立。

## 本轮要回答的三个问题（按此顺序）

### Q1 换脸插件可行性
- 已知：旧仓库 `Gourieff/comfyui-reactor-node` **已被 GitHub 封禁（403, staff disabled）**；新仓库是 `Gourieff/ComfyUI-ReActor`（★1384，2026-10-15 仍在更新），节点含 `ReActorFaceSwap / ReActorFaceSwapOpt / ReActorRestoreFace / ReActorFaceSimilarity`。
- 已试过并**已彻底回滚**：clone 新仓库 → 其 `install.py` 会先下 `inswapper_128.onnx`（529 MB，HF `Gourieff/ReActor`）再装依赖；本机下载到 30 MB 时中断，**pip 依赖一个都没装**，仓库与半截模型已删，环境干净。
- 你要查清并给出结论：
  1. Python **3.13** 下 insightface 有没有可用轮子（无则需编译，需 MSVC，风险高）；ReActor 新版是否已不再依赖 insightface（它带 `r_facelib`）。
  2. torch **cu130** + onnxruntime-gpu 是否可用；不可用就走 CPU EP（单张换脸 CPU 几秒，可接受）。
  3. 需要哪些模型、多大、放哪个目录（`models/insightface/`、`models/facerestore_models/`；本机已有 `GFPGANv1.3.pth`）。
  4. 8GB 显存够不够，峰值占用大概多少。
  5. 一次换脸耗时。
  → 输出：**可行性评级（高/中/低）+ 阻塞点清单 + 若要装的完整命令（含可卸载步骤）**。

### Q2 把 Qwen 的输出当换脸源，有没有效果
- 动机：真人的参考照只有 1254×1254 一张（头宽 553 px）；而 Qwen 编辑出的“隐约是她”的脸，可能在皮肤/光照上更贴合目标图。
- 要设计 A/B：源 A = 真人参考照；源 B = Qwen 编辑输出的脸（裁切放大到 512–1024）；目标 = 同一张全身图（928×1664）。**只变“源”，其余全同。**
- 要回答：换脸算法对“源是 AI 生成脸”是否敏感（inswapper 用 ArcFace embedding，理论上不挑来源）；风险是 Qwen 的脸本身已经偏离本人，换上去只会把偏差固化。

### Q3 效果到底有多少（必须量化）
- 推荐用 `ReActorFaceSimilarity` 节点（同仓库自带），或直接用 ArcFace（`buffalo_l` 的 `w600k_r50.onnx`）算余弦相似度。
- 需要给出的分数矩阵：
  | 组合 | 相似度 | 备注 |
  |---|---|---|
  | 参考 vs 参考（自比） | 1.00 | 校准用 |
  | 参考 vs 原全身图（未换脸） | ? | 基线，预期极低 |
  | 参考 vs ReActor 换脸后 | ? | 主结果 |
  | 参考 vs Qwen 编辑后 | ? | 已知"隐约像" |
- 判读口径：ArcFace 同人一般 ≥ 0.45–0.55（不同阈值实现略有差异，需说明用的是哪个）。**低于基线就判否决，不要含糊。**
- 另外必须回答“清晰度”：换脸后脸在 131–233 px 时，是“像但糊”还是“糊到不可用”；以及**能救到多少**（例如换脸后再做一次 1024 脸修复，是否值得）。
