# 换装 / 上身：身份像素门槛与白模替代路线

## 1. 1/2 像素门槛（判「能不能做」的唯一硬指标）

- 量法：锚图脸高（下巴→发际线）vs 出图脸高，算比值。
- 规则：**出图脸 ≥ 锚图脸 × 0.5**；低于 0.5 = 五官必被重画（不是「模型不懂」）。
- 换算（出图 1920 高时出图脸高）：腰以上半身 ≈576px / 到腰 ≈345px / 膝以上 ≈268px / 全身 ≈172px。
- 例：特写锚图 755px → 只能做腰以上（0.76×）；做全身 = 0.17× 必漂。全身级锚图 211px → 全身 0.82× 可用。
- **推论：锚图要分级** —— 特写级（脸 700px+，近景/半身）与全身级（脸 150–250px，膝以上/全身）。拿错级别 = 白跑一轮。

## 2. 锚图构图会被继承

参考图的留白与人物占比会被照抄，文字里的「人占 90%」压不过它。

- 做法：进第一槽之前先重构图 —— 人占画面 90%、头顶 5%、脚底 5%、中心轴对齐，再放大到目标尺寸。
- **输出尺寸跟第一槽走**：要 1088×1920，就把锚图先做成 1088×1920；否则出图仍是锚图尺寸。

## 3. 比例必须写数值，不能写形容词

- 头身比（男 7.5 / 女 7.5 / 时装 8.0）、肩宽 = 2.2–2.4 × 头宽、腿（裆→地）= 0.47–0.48 × 身高、脚长 ≈ 头长 × 0.95–1.0。
- 相机也写死：腰高平视、85mm、3.5m → 透视不拉伸。
- 判据（出图后量）：头长、肩宽、人物占画面高、脚长。脚偏小 / 肩宽<2×头宽 / 腿<45% 一律判不合格。

## 4. 白模替身两段式（换装测试首选）

白模 = 有头**无脸**的白关节人偶：没有脸要保 → 全部像素给布料 → 领型/扣子/缝线第一次有足够像素承载。

1. 第一段：白模 + 服装（变量只剩衣服），把版型与件数调对。
2. 第二段：衣服定稿后，再换真人身体（此时衣服已收敛）。

白模提示词要点：`egg-shaped blank head`（no eyes / nose / mouth / hair）、`visible ball-and-socket joints`（肩肘腕髋膝踝）、`satin-matte white resin`、禁 gloss / chrome。
负向必含：`human face, facial features, skin tone, hair, doll face, barbie, anime`。
换装时再加：`garment hovering, clothes not touching the body, sticker clothes, mannequin stand, support pole, base plate`。

**两个常见漂移**：① 白模偷偷变真人（出现皮肤/五官/头发 → 直接判废）；② 衣服悬空成贴纸。用关节参照句压住：袖口到腕关节、裙腰在腰上、裙摆过膝上方、鞋把脚包住、手指要露在袖口外。

## 5. 判据（换装输出逐项核）

1. 件数对不对（多件/少件/被合并）
2. 可数细节在不在（领型、蝴蝶结、荷叶边、扣子、口袋、裤线、鞋型）
3. 穿得住吗（袖口/腰线/下摆/鞋是否落在对应身体位置）
4. 身体特征是否保留（白模的关节、真人的脸与痣）
5. 衣服有没有重量感（褶子、垂坠、接触阴影），不是贴上去的图
