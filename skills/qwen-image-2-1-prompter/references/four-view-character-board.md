## 提示词修订顺序

1. 读取实际 PNG 元数据，确认比较同一输出阶段，递归比较完整节点、图像哈希、连接、正负向、种子与参数。不能仅比较标量或归一化后的字符串。
2. 保留成功原文。候选从指定失败基线只更改一个已声明的提示词块，完整交付正负向，固定其余输入。文本检查 PASS 只说明约定改动范围，不等于图像成功。
3. 优先检验每格分别限定无头并保留肩臂手。旧骨架将共同无头句放在侧面后，且混用了服装领口与身体肩线；这是可检验假设，未获得新图前不标为解决。
4. 视觉验收必须同时涵盖前三格无头、肩臂手完整、正背侧方向、衣服款式和印花、第四格身份、整体布局；侧面允许自然遮挡。

## 撤销的旧规则

不得再宣称“真因是不可复现”、要求同 seed 跑 3 张挑选、把 QwenImage21Cache 当已查明原因、将连身裙伪写成两件式、固定切掉胸口以上约 17%、连败两次就要求换衣。当前证据没有支持这些修法。裸写 image token 是格式规范，反引号不等于图像连线断开。

## 遮罩后备

保留一次整图采样，用保护遮罩限制前三格肩上背景在 latent 中不可重绘，原则可行；必须与服装/身体边界分开。Muse 工作流缺少实际 mask 文件与必填 channel，且原图 VAE 编码和参考图编码的尺寸不同。先修正并验证这些条件，不能据该 JSON 承诺永久无头，也不能以遮罩同时改动提示词来做单变量实验。
